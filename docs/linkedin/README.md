## Règles qui font marcher ces posts
1. **Accroche sur 2 lignes** (avant le "…voir plus"). Tout le reste sert à gagner le clic.
2. **Pas de lien dans le post** : le lien vers le site va dans le **premier commentaire** (LinkedIn réduit la portée des posts avec lien externe).
3. **Mot-clé en commentaire** ("Commentez PMP") : chaque commentaire booste le post et vous donne un lead à contacter en message privé.
4. **Répondre à tous les commentaires dans la première heure.**
5. **Préparer les lead magnets** avant publication (checklist PMP, guide SAFe, etc.) : un PDF de 1 à 3 pages suffit.
6. Les citations d'avis (J7, J20) doivent être **de vrais avis** copiés depuis Trustpilot / Google, avec accord du stagiaire si son nom apparaît.

## Programmer les posts
- **LinkedIn natif** : "Commencer un post" → icône horloge → date et heure. Gratuit, jusqu'à 3 mois à l'avance.
- **Outils** : Buffer, Hootsuite, Taplio ou Metricool (utile pour les carrousels PDF et les statistiques).

## Veille "posts viraux des 15 derniers jours" (à refaire chaque lundi, 20 min)
1. Recherche LinkedIn : `PMP`, `Scrum Master`, `SAFe`, `PRINCE2`, `chef de projet`, `gestion de projet`.
2. Filtre **Posts** → **Date de publication : semaine / mois dernier** → trier par **Pertinence**.
3. Noter les 5 posts avec le plus de commentaires : accroche, format, sujet.
4. Réutiliser **le format et l'angle**, jamais le texte : écrire avec votre expérience et vos chiffres.
5. Outils qui automatisent cette veille : Taplio, Shield Analytics, Kleo (extension Chrome).
